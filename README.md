
# 🍽️ Smart Menu System

An **IoT-based Smart Menu System** developed using **ESP32 and Arduino IDE** to automate restaurant ordering and enhance the customer experience.

## 📌 Project Overview

The **Smart Menu System** allows customers to browse a digital menu, place or cancel food orders, and make payments through a web interface.

The system uses an **ESP32 microcontroller** to communicate with various hardware components and display menu and order information.

## ✨ Features

* 📱 Digital menu display
* 🍔 Place and cancel food orders
* 💳 QR code-based payment
* 📟 LCD display for menu and order status
* 👤 Customer detection using IR sensor
* 🔔 Buzzer and LED notifications
* 🌐 User-friendly web interface
* ⚡ Real-time order management

## 🚀 How to Run

### 1. Install Arduino IDE

Download and install **Arduino IDE** on your computer.

### 2. Install ESP32 Board Package

Open Arduino IDE and install the required **ESP32 board package**.

### 3. Connect Hardware

Connect the ESP32 with the LCD, keypad, IR sensor, buzzer, LED, and other required components.

### 4. Open the Project

Open:

```text
Smart-Menu-System.ino
```

in Arduino IDE.

### 5. Upload the Code

Select the appropriate ESP32 board and COM port, then upload the code.

### 6. Start the System

Power on the ESP32 and access the web interface to interact with the Smart Menu System.
